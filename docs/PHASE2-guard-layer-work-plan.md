# Phase 2 work plan: from spike guards to one guarded layer

Written 2026-10-24 from the Phase 1 tree (SolidCraft 0.9.0 contract, commit `2b26d633` and later). It is a plan, not a build: nothing below has been done yet.

## Why this is not a quick merge

Phase 1 measured the layer one group at a time, and each group's builder wrote its own copy of the translator. What exists under `docs/spikes/solidcraft-referee/`:

- `phase0/translate.mjs` (426 lines) is the base translator, ModelDoc to SolidCraft commands.
- Group forks of it: `contract/translate-ep.mjs` (1091) and `translate-ep.round2.mjs` (967) for extrude-pocket, `holes3-translate.mjs` and `holes4-translate.mjs`, `pm-translate.mjs` (1000) for patterns-mirror, `shell-draft-translate.mjs` (950), `bool-translate-r3.mjs` (generated by `make-bool-translate-r3.mjs`), `revolve-groove-rig/rg-translate-p0.mjs` and `rg-translate-p4.mjs`. `translate-ep.mjs` differs from the base by about 850 diff lines.
- Pure guard modules (no kernel, no wasm), each with its own entry point: `primitives.guard.mjs` (`guardFeature`, `guardDoc`) with `primitives.call-lint.mjs`, `outline-guard.mjs`, `blend-loft.guard.mjs`, `revolve-groove.guard.mjs`, `sketch-geometry.guard.mjs` (`guardClassic`, `guardSoup`, `guardFrame`), `booleans.guard.mjs` (`guardCombine`, `afterCombine`, `plainSentence`), `fillet-chamfer-evidence/fc-guard.mjs`, `sketch-constraints-r5/guard.mjs`, `picks-naming-params.evidence/r3-guard.mjs`, `sketch-dof-diagnosis/*-guard.mjs`.
- Four groups are not accepted (booleans, patterns-mirror, revolve-groove, sketch-geometry). Their guards have known holes listed in `LAYER-CONTRACT.md`.
- A guard decides before a build (pre-flight) or after (booleans G19/G21 `afterCombine`). Some also need a Worker with a time budget (booleans 45 s). The unified layer must support both.

None of the guards is called by the product. Until they are, every row the contract lists as `wrong` is a wrong solid a student can get.

## Order of work

1. **Contract for the layer.** One function: `buildDoc(doc, engine) -> { features: { [id]: built | { refused: sentence } } }`. It is the existing `EngineBuildResult.refusals` in `packages/brep-adapter/src/engine-adapter.ts`. Write the types and an `engine` interface that `window.solidcraft` (host page) and the wasm rig (tests) both implement. No kernel names above the interface.
2. **One translator.** Take `phase0/translate.mjs` as the base and fold each group's fork into it in a fixed order: extrude-pocket, holes, shell-draft, patterns-mirror, booleans, revolve-groove. After each fold, replay that group's committed evidence rows and require the same status and sentence as the contract (the `--check` recipe already does this per group). Stop a fold the moment a row changes.
3. **One guard pipeline.** A single `guardDoc(doc)` that calls the pure guards in a fixed order and returns the first refusal per feature, plus a post-build hook for `afterCombine`. Port the pure guards first (primitives, outline, blend-loft, revolve-groove, sketch-geometry), then the ones tied to a translator (booleans, patterns-mirror, shell-draft).
4. **Close the unresolved holes** before they ship: the four unresolved groups, and the move-turn `copy:"yes"` / `copy:1` gap (no guard exists).
5. **Where it lives.** A new package under `packages/` (name open), built after `sketch -> script -> brep-adapter` in the manual build chain. Not inside `packages/script`: the interpreter must never reach the main app origin, and the layer must be importable by the host page.
6. **Fuzz exit.** The fuzz (`fuzz/oracle.mjs`, `fuzz/repros/`) shows built-or-refused for every case, never a wrong solid, on the pinned SolidCraft. Re-run the contract on any new pin (`contract/run-contract.sh`).

## Not decided here

- Which SolidCraft version is the pin. Phase 1 is measured on 0.9.0 (`fe3717f`); a 0.21.0 measure pass exists in `/tmp/contract-0.21.0` but its rows were not rebuilt cleanly (see the session notes). Guards tuned on 0.9.0 numbers are not known to hold on 0.21.0.
- Package name and whether the guards stay `.mjs` or become TypeScript (the repo convention is TypeScript, `strict`).
- The ribbon lock and the upstream request (`docs/DRAFT-upstream-ribbon-request.md`, not filed).

## Risks

- A fold that quietly changes behaviour. Mitigation: per-group replay of the committed rows after every step, never a bulk merge.
- Guards that over-refuse. Phase 1 measured some at roughly half of move-turn cone chains and about 74% of fuzz shell cases. The exit must also check that plain plates students will try still build.
- Carrying guards tuned on 0.9.0 onto another kernel version unchecked.
