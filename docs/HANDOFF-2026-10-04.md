## Owner decisions made

- Sketch corner numbers are 1-based now (`.round(k)`, `.chamfer(k)`). Stored docs stay 0-based; the emitter writes +1. A corner number of 0 stops with a sentence; an old corner number 3 means the third corner now (a test pins it). No shCode lesson uses it.
