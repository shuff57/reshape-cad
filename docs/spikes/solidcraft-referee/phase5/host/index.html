Known limits (phase 2 findings, not hidden)

  • solidcraft's tangent constraint is satisfied only to about 1e-4 mm at the joint while its report says solved; volumes stay inside the 3e-4 bar.
  • Its dof / redundancy report depends on the start state: an already-tangent sketch can read a higher dof than the hand count.
  • It refuses redundant dimensions that brep-rs and FreeCAD accept (stricter, not wrong).
  • Angle and signed distanceX/Y have no branch parameter: mapped only when the drawn start is already on the requested branch; otherwise refused with a sentence.
  • Phase 4: named picks (a round / chamfer edge, a shell's open face, a draft face) are resolved from solidcraft's OWN topology, by geometry, with two cross-checks; a name that matches zero or several candidates, or a cause this demo does not implement (rounded / split / made, a swept name over an arc, rotated or rounded primitives), is refused with a sentence naming the count. Never the nearest one.
  • Friendly sketch (phase 5): a sketch() with nothing drawn on it is the interpreter's DEFAULT 40 x 25 rectangle, and extrude pulls it silently (the shim cannot see extrude). Emptying a sketch with sk.remove() IS refused.
  • Friendly sketch: sk.angle, sk.dx, sk.dy are DIRECTED. solidcraft refuses a drawn start that disagrees with the sign ("would apply the value to the opposite orientation"); draw the start on the side you mean. An arc's 'cw'/'ccw' picks the sweep: the wrong word draws the other arc (270 deg instead of 90) with no warning. sk.remove() drops every rule that names the shape, dimensions on other shapes included.
  • Demo caps (so a run finishes in seconds): at most 100 pattern copies in total (100 copies took about 4 s, 200 took 35 s, 1000 took over 170 s), at most 60 features (6-8 s; 150 took 33 s), dimensions up to 1,000,000 mm, and a 10 s limit on evaluating the script in the sandbox. Above a cap the run is refused with a sentence before anything is built.
