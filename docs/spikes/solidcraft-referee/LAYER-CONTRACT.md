## How to read this
- **supported**: built and equal to an independent measure within the stated tolerance.
- **refused**: not built; the student sees one plain sentence and the rest of the part is shown.
- **wrong**: the kernel builds a solid that disagrees with the independent measure and nothing stops it. This is the dangerous class; every `wrong` row is listed below.
- **unsupported**: the language or the translator has no route; no solid is claimed.

**Guards are not shipped.** In every group the guards live in files under contract/ (spike grade). None is wired into the product page or the translator that ships; the page today shows the unguarded translator's output and, for refusals, kernel wording. A row marked refused or supported-with-guard describes the GUARDED route and is only true once that guard ships. The rows file of each group says per row which route a status describes.
