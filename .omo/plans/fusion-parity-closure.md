# fusion-parity-closure - Work Plan

## TL;DR (For humans)

**What you'll get:** reSHape Studio's mouse interactions closed to match Autodesk Fusion — finishing the ViewCube, 3D selection tools, a right-click marking menu, and on-canvas manipulators for extrude/fillet/move — plus a self-testing pipeline: the app records itself performing every new feature and an AI watches the recording to confirm it works and flag anything that still looks off.

**Why this approach:** exploration found most of the camera and sketch work already shipped, so this plan builds only what's left (selection tools, right-click menu, 3D manipulators) instead of re-doing finished work; and every wave is required to prove itself with a recorded demo before moving on, so nothing gets marked done on trust.

**What it will NOT do:** won't add a second CAD engine or change the reference-comparison tests; won't rebuild anything already working; won't commit any of the recorded videos to the repository; several open behavior questions (exact click-and-hold timing, marquee-selection direction) stay flagged as unresolved unless a real Fusion recording settles them, rather than guessed at as final.

**Effort:** XL
**Risk:** Medium - touches files another work-in-progress stream is actively editing, and about a third of the work (the right-click menu, 3D manipulators) is new UI with no existing precedent to copy from.
**Decisions to sanity-check:** flipping the default mouse control scheme to Fusion's layout (todo 29) changes muscle memory for anyone already using the app; a few small tools (sketch fillet, trim, offset) get built mainly to file honest video-review evidence, not because they were separately requested.
